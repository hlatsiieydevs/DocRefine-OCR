## Changes
- Created `Automation_Pipeline.ipynb` to handle the full automated Word document generation and image extraction process.
- Implemented environment setup with automated extraction directory creation inside `data/output/` and log directory generation at `logs/process_logs/`.
- Written `extract_image_blocks` function utilizing placeholder relative heights to crop "Comments", "Signature", and "Date" blocks adaptively.
