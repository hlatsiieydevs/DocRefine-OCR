## Changes
- Created standalone execution script `run_pipeline.py` to handle consolidated document generation, conversion, and reporting.
- Refactored score distribution calculations:
  - `WPL_02`: Calculates Q1T and Q2T (combined total $T2\% \times 56$), randomly distributes scores among 7 ELO categories in range $[2, 4]$ (or $[0, 3]$ for low score cases $< 50\%$). Enforces $Q2T \ge Q1T$ when $T2 \ge 50\%$.
  - `WPL_04`: Calculates XT ($T4\% \times 28$), distributes among 7 ELO categories in range $[2, 4]$ (or $[0, 3]$ for low score cases $< 50\%$).
- Automated lookup of final scores from `MIP360S_Results.csv` using the student numbers (with split-based matching to support multiple student numbers).
- Implemented registered signature check: checks `data/signature/mentor_signatures/{page_no}.png` and bypasses alignment/cropping if signature exists. Fallbacks to raw scan processing if signature is missing.
- Added headless PDF conversion using LibreOffice (`libreoffice --headless --convert-to pdf`). Output documents saved as separate PDF files (cover pages and rubrics for both `WPL_02` and `WPL_04` configurations, with cover pages in landscape and rubrics in portrait orientation).
- Implemented process reporting system tracking fully completed records, empty score sheets, missing student metadata, and records flagged for review.

## Notes
The cover page template was updated by the user to use `ach_state` and directly embed the WIL coordinator's signature image, eliminating the dynamic `wil_signature` cover context. We successfully aligned the Python context variables to these modifications.
